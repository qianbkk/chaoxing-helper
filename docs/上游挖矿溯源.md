## 四、这次核实的空白（诚实标注）

- GF 530068 在 **2025-03-17 ~ 2025-03-29**（脚本创建后头两周）的版本**没能逐个核对**：
  Greasy Fork 的"显示全部版本"页（`?show_all_versions=1`）被 Cloudflare 挑战拦截，
  只能拿到可见的最近 50 个版本（最早为 v5.1.4 / 2025-03-30，已确认干净）。
  ⇒ 结论对该脚本成立，但未做到 100% 逐版本核验。
- GF 484657 的 5 个版本是**完整列表**，该脚本已 100% 核过。
- 「正则修改版」这个二次打包版本的**公开出处没有找到**（Greasy Fork 搜索页同样被 Cloudflare 拦截）；
  只能从文件自述确认它是"基于正则修改版"的第三方修改，来源公众号为"一只哥哥"。
