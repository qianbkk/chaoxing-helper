## §2 为什么这个项目存在

起点是一个很具体的症状：**刷课正常、做题目不行**。
视频能刷、进度能保，但一到章节测验就卡住 —— 答案要么匹配不上选项，要么算出来的「正确率」永远不达标，
于是脚本每回都只保存、不提交。追下去是三条根因叠在一起（总体脉络见 [AI答题改造方案.md](AI答题改造方案.md)）：

1. **早期版本依赖的备用查题服务器实测已下线**（TCP 不通），查题请求必然超时；
   留着它只会让每一道题白白多等一次超时。
   *依据：`AI答题改造方案.md` 的 P0-9 条目。*
2. **接口的流控返回码没被识别为失败**：题库接口触发限流时返回一个负数码，
   早期代码把它漏过去了，直接把「触发流控限制」的提示**当成答案文本**去匹配选项，
   于是怎么匹配都对不上。
   *依据：`AI答题改造方案.md` 的 P0-8 条目。*
3. **正确率默认 100%，而填空题被跳过却仍算进分母** ⇒ 正确率在结构上永远到不了 100%
   ⇒ **永远只保存不提交**。
   *依据：`AI答题改造方案.md` 的 P0-11（分母口径）与同文档「关键设计决策」表里的正确率门槛默认值那一条。*

这三条决定了本项目后来所有改造的方向：把「查题」这一环换成让 AI 直接给出选项序号，
同时把正确率口径、提交条件、题库降级三处逻辑重写。

## §3 已经移除的早期行为

早期脚本里有两处会带来安全与隐私问题的行为，本项目**都没有继承**，
而且是在动手做别的改造之前就先把它们摘掉了。

### 3.1 早期脚本会注入第三方浏览器挖矿脚本

- **结论**：带挖矿注入的是早期流传的**第三方二次打包版本**。
  **本项目从第一个版本（v1.1）起就把这段注入删掉了**，删在它原本所在的那几行上，
  原位置只留了一行说明注释（发布件里那行注释已脱敏，不含域名与账号）。
  *依据：`CHANGELOG.md` 的 v1.1.0-AI 条目。*
- **影响**：装本项目不会替任何人挖矿。早期版本「不占资源」的说法与本项目无关 ——
  挖矿线程是要吃 CPU 的。
- **顺带澄清一条**：上表里那两份 Greasy Fork 脚本的**全部历史版本都没有挖矿代码**，
  坑在第三方二次打包，不是原版作者的锅。
- **怎么自查**：
  1. 在脚本管理器里逐个检查你装过的脚本，全文检索**关键词类别**：
     浏览器挖矿脚本的常见标识词（由 `WEB` 与 `MINER` 两段拼成的那种）、挖矿脚本的常见文件名、
     常见挖矿域名片段 —— 命中即为可疑。
  2. 打开超星学习页后看浏览器网络面板：有没有向陌生域名发起的**脚本**请求，
     以及页面加载二十来秒后凭空多出来的外部请求。
  3. 开着学习页不动，看浏览器进程的 CPU 是否明显高于正常。
- **已脱敏**：本仓库与发布件里都**不含可用的挖矿地址与账号**；
  完整的取证过程（逐版本核对记录）留在私有存档仓库 `qianbkk/scriptcat-chaoxing-helper` 的 Git 历史里。

### 3.2 早期脚本有两处把课程 ID、账号 UID、学习进度明文 HTTP 发往第三方地址

- **是哪两处**：
  1. **刷视频取签名令牌**：向一个第三方服务器发请求拿进度上报所需的签名，
     请求里带着课程 ID、账号 UID、学习进度与章节时长，而且是**明文 HTTP**（没有证书，可被中间人改写）。
  2. **查题兜底**：题库查不到时把题干发到另一个第三方地址（该开关硬编码为关闭、面板没有入口）。
- **为什么移除它们是行为等价的**：这两个地址**早已下线**（实测 TCP 不通），
  脚本实际一直走的是它的**本地分支**（签名由脚本本地计算）。
  也就是说留着它们 = 每章白等一次超时 + 把 UID 和学习进度发给第三方；
  删掉之后，**今天真正生效的那条路径一点没变**。
- **发布件现在只联系三类地址**：
  1. 超星自己的域名；
  2. 你自己配置的 AI 接口；
  3. 你自己配置的题库接口。
- **依据**：`CHANGELOG.md` 的 v1.9.0 条目；发布件侧的断言在 `tests/release-meta.test.js`
  （两处外发的请求路径均为 0 命中，本地分支仍在）。

## §4 安全现状

- 仓库与发布件**不含任何挖矿载荷**；
- **不含他人的个人信息**（上游源码里的作者邮箱已移除，上游源码本身不再随包分发）；
- **不含任何密钥**：API Key 与题库 Token 由使用者自己在面板里填，
  只存在各自浏览器的脚本管理器存储里，不落进本仓库；
- 正式版的更新地址只指向本项目自己的发布页，**不含本机地址**；
- 以上几条由 `tests/release-meta.test.js` 在**每次构建时自动复查**，不靠人记得看一眼。
