## 一、为什么要做这一版

v1.2 之前，这些功能被判定为"不采纳"（体量大、依赖多、当前用不上）。
按新的决策，它们改为 **「基础整理 + 明确标注未验证」** 的形式纳入项目：

| 原判定 | 现在 | 实现方式 |
|---|---|---|
| 考试端（超星旧版/新版考试 + 作业） | 纳入 | **自己重写精简版**，只借鉴已有的选择器写法，不移植那 5000 行 |
| 阅读时长 | 纳入 | 精简版阅读助手：自动滚动 + 本地计时 |
| 图书 | 纳入 | 合并进"阅读/图书"（没有独立的图书模块，见第四节） |
| 直播任务 | 纳入 | 没有现成实现 → 用面板里的"任务页关键词"自定义匹配后保活 |
| 强制复制粘贴 | 纳入 | 移植 `pasteEnabler` 的做法，改写为 ES5 |
| 多题库并行投票 | **不纳入** | 实测只有 1 个免费题库，见第五节 |

全部**默认关闭**，需要在学习端面板的 **「附加功能（实验性 · 未验证）」** 里手动勾选。

## 二、模块一：强制启用复制粘贴

**来源**：早期从 GF530068 v5.5.9.9.6 的 `pasteEnabler` 移植，改写为 ES5
（参考实现不再随包分发，在线地址见 [来源与安全说明.md](来源与安全说明.md) §1）。

**作用是什么**：超星的某些课堂测试/在线作业会禁用复制粘贴（`onpaste="return false"`、
`user-select:none`、阻止 `contextmenu`）。禁用后你连题干都拿不出来，
既没法去搜题，也没法问 AI。本模块解除这些限制：

- 清掉 `document.onpaste/oncontextmenu/onselectstart/ondragstart/oncopy/oncut`；
- 逐个元素清掉 `onpaste` 等内联属性、`readonly`、`disabled`；
- 注入 `user-select:text !important` 样式；
- 捕获阶段放行 `contextmenu`（右键菜单）；
- MutationObserver 持续处理新插入的输入框。

**适用场景**：禁用复制粘贴的课堂测试 —— 有用，可以把题干复制出来搜题。
**不适用**：没有禁用限制的普通章节页 —— 开着也无害。

**已知限制（未验证）**：如果页面用 `addEventListener('paste'|'copy', e => e.preventDefault())`
来阻止，本模块**不一定**能解除（因为阻止发生在事件冒泡到页面监听器时）。

## 三、模块二：考试 / 作业端自动作答

**来源**：早期从 GF530068 v5.5.9.9.6 的 `WorkerJSPlus` 移植的 4 个超星页面适配，
改写为本项目自己的精简实现。

### 支持的页面（路径判定见 `extras.matchExamPage`）

| 页面 | 路径 | 题目根节点 | 题干选择器 |
|---|---|---|---|
| 旧版考试 | `/exam/test/reVersionTestStartNew`（**不带** `newMooc=true`）<br>`/exam-ans/exam/test/reVersionTestStartNew` | `.TiMu` | `.Cy_TItle .clearfix` |
| 新版考试 | 同上路径**带** `newMooc=true`，或 `/mooc2/exam/preview`、`/exam-ans/mooc2/exam/preview`、`/mooc-ans/mooc2/exam/preview` | `.questionLi` | `h3 div` |
| 新版作业 | `/mooc2/work/dowork`、`/mooc-ans/mooc2/work/dowork` | `.questionLi` | `h3 div` |
| 旧版作业 | `/work/doHomeWorkNew`、`/mooc-ans/work/doHomeWorkNew` | `.clearfix .TiMu` | `.Zy_TItle .clearfix` |

### 答题链路（与学习端一致）

```
题库(icodef, type=0/1/3) ──命中文字匹配──► 勾选
        │ 未命中 / 超时
        ▼
AI(OpenAI 兼容 /chat/completions) ──返回序号──► 勾选
        │ 未配置 / 失败
        ▼
随机兜底（单选/判断取第 2 项，多选全选）
```

- 题库返回的是**答案文字**，用 `extras.matchAnswerText` 做"去空白 + 去选项字母前缀 + 去标点"的**全等优先、次选包含**匹配；
- AI 返回的是**选项序号**，复用 AI 模块已有的 `parseAnswerIndex`；
- 多选题会**取消没选中的项**（`clickOption(input, true)` 强制点一次）。

### 行为边界（有意为之）

- **不自动交卷**：只作答 + 自动翻"下一题"；
- 翻页只在页面上**找到唯一**一个含"下一题"的按钮时才点（避免误点），最多翻 100 页；
- **填空/简答（UEditor）未实现**：超星用 `UE.getEditor(name).setContent()` 填，依赖页面 UEditor 实例，本版不碰；
- 超星旧版考试的多题连续页结构未逐一验证。

## 四、模块三：阅读 / 图书 / 自定义任务页保活

### 前提事实（重要）

在参考实现 GF530068 v5.5.9.9.6 里，**没有**独立的"图书模块"和"直播模块"——
全文检索 `图书|book|library` 与 `直播|live` 均 0 命中（唯一一条 "Live" 是无关的 Live2D 看板娘外链）。
那里只有**阅读助手**（对应脚本里的阅读助手段），对应 URL：

- 阅读任务目录页：`/mooc-ans/zt/portal/`、`/mooc-ans/course/*.html`、`/course/{数字}.html`
- 阅读正文页：`/ztnodedetailcontroller/visitnodedetail`

⇒ **图书任务实际走的就是这套阅读 URL**，所以本模块把两者合并成一项。

### 本模块做了什么（基础整理版）

- 识别上述阅读页面 → 每隔 N 秒（默认 8 秒，面板可调）自动滚动一段段落/像素，
  让超星自己的阅读页 JS 认为你还在读；
- 本地计时（`GM_setValue('unrivalExKeepSec')`），每分钟往面板日志写一次；
- **直播等没有现成实现的类型**：用面板里的「任务页关键词」（逗号分隔，如 `live,ztactivity`）
  匹配当前 URL，命中就走同样的保活逻辑。

### 未验证点（重点）

- 参考实现里的阅读助手是**纯前端滚动 + 本地计时**，不调用任何超星接口；
  **超星最终是否把时长计入成绩，取决于服务端统计，本模块无法保证**；
- 本版没有移植更完整版本的"自动翻下一章"、目标时长达标徽章、快捷键（K/Z/S/R）、浮动面板；
- 图书/直播的 URL 特征**没有可参考的依据**，靠面板关键词手填。

> ⚠️ **面板变更**：v1.6 起，「阅读/图书任务页保活」这一项已从面板移除
> （实测对该类任务无效，别再白勾），见
> [v1.4章节测验与字体解密说明.md](v1.4章节测验与字体解密说明.md) §6.2.5。

## 五、多题库并行投票：实测后决定**不做**

2026-11-23 实测：

| 题库 | 结果 |
|---|---|
| `cx.icodef.com/wyn-nb`（icodef） | ✅ 可用；**无 token 也能查**（token 只提高并发，无 token 时 1 并发、连发 3 次触发 `code:-2` 流控） |
| `lyck6.cn/scriptService/api/autoFreeAnswer`（GF 530068 用的后端） | ❌ 本机 TLS 握手失败（`schannel: failed to receive handshake`）；且它是该作者的**商业服务**（404小站），不是公共免费题库 |
| `tiku_adapter` 那一套 | ❌ 是让用户**自己填**的自定义接口，不是现成题库 |

⇒ **可用的免费题库只有 1 个**，"多库并行投票"没有意义（1 票 vs 1 票）。
按你的指示：**维持现状「题库优先 → 连续 3 次失败熔断 10 分钟 → 全程转 AI」**，不引入投票机制。

## 六、怎么用

1. 导入当前发布件 `dist/chaoxing-helper.user.js`（安装与更新见 [安装与自动更新.md](安装与自动更新.md)）；
2. 打开超星课程章节页（脚本面板所在处）；
3. 面板里找到 **「附加功能（实验性 · 未验证）」**，勾选需要的项 → 点「保存附加功能设置」；
4. 考试端：进入考试页，脚本自动识别并作答（**不会自动交卷**，交卷请自己点）。

## 七、后续研究建议（等你有空时按这个顺序做）

1. 拿一个真实账号打开**旧版考试页**（`/exam/test/reVersionTestStartNew`），
   把 `console` 里 `extras.collectExamQuestions('examOld')` 的输出贴回来 → 校准选择器；
2. 再试**新版考试**（带 `newMooc=true`）与 `/mooc2/exam/preview`；
3. 填空题：研究超星 UEditor 实例的调用方式（可参考的写法是 `UE$1.getEditor(name).setContent(answer)`）；
4. 阅读时长：打开一个真实的阅读任务页，观察超星是否上报时长、本模块的滚动是否够；
5. 直播/图书：把真实页面的 URL 关键词填进面板，确认匹配后再固化为内置规则。

> 未验证的功能一律在源码、面板、文档里标注「未验证」，不做"看起来能用"的承诺。
